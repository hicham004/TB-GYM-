# Instrument Serif

Unmodified Instrument Serif Italic (400), Latin subset, used only for the italic accent words in
the public homepage headings. Self-hosted WOFF2: no third-party browser requests or new package
dependencies. Android has no Georgia, so a system serif would change the page's look per device.

Source: Google Fonts CSS2 API, `family=Instrument+Serif:ital@1`, latin subset (v5).
