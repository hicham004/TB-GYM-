# Instrument Serif

Unmodified Instrument Serif Italic (400) and Regular (400), Latin subsets. The italic is the accent
face of the signed-out screens and the app's moments; the upright (added 2026-10-13, UI plan R6.2f) is
the homepage's numerals. Self-hosted WOFF2: no third-party browser requests or new package
dependencies. Android has no Georgia, so a system serif would change the page's look per device.

Source: Google Fonts CSS2 API, `family=Instrument+Serif:ital@1` and `family=Instrument+Serif`, latin
subsets (v5).
