# IBM Plex fonts

Unmodified IBM Plex Sans and IBM Plex Sans Arabic, Regular (400) and SemiBold (600).
Self-hosted WOFF2 files: no third-party browser requests or new package dependencies.

Source: https://github.com/IBM/plex/tree/bf260093582f04622aacc1e9f9ca604d7ccd0c42/packages

Paths: `plex-sans/fonts/complete/woff2/` and `plex-sans-arabic/fonts/complete/woff2/`.
